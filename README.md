# 오답법정 · 미적분Ⅰ

픽셀 법정에서 풀이의 첫 오류를 찾고 증거로 판단하는 수학 추리 게임입니다.

## 직접 만드는 증거

첫 연습 사건의 증거 조사에서는 기울기를 조절해 `f(x)=ax-1`의 반례를 직접 제출합니다. 원래 조건 `f'(x)>0`, `f(0)=-1`을 모두 만족하면서 `f(1)>0`을 반박해야 합니다. `0<a<=1`을 인정하며, 경계값 `a=1`에서는 0과 양수의 차이를 다루는 별도의 반대신문이 이어집니다. 제출한 함수와 반론 진행도는 자동 저장됩니다. 튜토리얼의 코인 보상은 없습니다.

`evidence-workshop.js`는 증거 작성·반대신문을, `workshop-graph.js`는 정확한 좌표의 흑백 그래프를 담당합니다. `workshopMathCorpus()`는 모든 기울기와 대사의 수식을 벡터 캐시 검증에 포함합니다. 업데이트 이전에 이미 채택된 연습 사건의 증거는 기존 진행 상태를 유지합니다.

## 플레이
튜토리얼 3단계와 극한·연속 / 미분 / 적분 기초 사건 6개, 심화 사건 2개를 제공합니다. 판사가 사건을 소개하고 상대측이 한 줄씩 진술하면 처음 잘못된 줄에 이의를 제기합니다. 오류 없는 풀이도 포함합니다. 사건 입장 시 법정문 연출은 건너뛰기·Escape를 지원합니다. 소리는 기본 꺼짐이며, 진행 상황은 해당 브라우저의 localStorage에 저장됩니다. 서버 계정 동기화는 없습니다.

## 개발
빌드 없는 HTML·CSS·ES modules입니다. 정적 HTTP 서버로 이 디렉터리를 제공하세요. `npm run check`로 문항·그래프·진술 진행·보상·수식 캐시 검증을 실행합니다. GitHub Pages는 main 브랜치 루트에서 배포합니다.

- `app.js`: 게임·기록·튜토리얼
- `cases.js`: 문항 및 해설
- `graphs.js`: 수학 증거 그래프
- `entrance.js`, `entrance.css`: 법정문 연출
- `style.css`: 픽셀 UI 및 반응형 화면

## 자산
법정 배경은 이 프로젝트를 위해 생성했습니다. Neo둥근모 Pro 글꼴은 SIL Open Font License 1.1입니다. 전문은 FONT-LICENSE.txt를 확인하세요.

## 수식 표시

문제·선택지·해설·그래프의 수식은 LaTeX로 작성하고 KaTeX 0.16.22로 표시합니다. 렌더러와 수식 글꼴을 함께 제공하므로 외부 CDN 연결이 필요하지 않습니다. KaTeX의 MIT 라이선스는 `KATEX-LICENSE.txt`에 있습니다.

## 보상과 해금

정식 사건 해결 30코인, 첫 시도에 진술 판단 10코인·증거 제출 5코인·논리 복구 5코인을 지급합니다. 동일 보상은 한 번만 지급하며 재심은 미획득 보상만 추가합니다. 최초 두 기초 사건은 무료, 다른 기초 사건은 누적60코인, 심화 사건은 누적100코인과 관련 기초 사건 완료로 열립니다. 튜토리얼은 보상이 없습니다. 기존 완료/진행 기록은 보존합니다.

## 캐릭터와 시험지 스타일

판사와 상대 변론인은 차분함·생각·기쁨·놀람·신중함·확신의 여섯 표정과 동작으로 진술/이의제기/증거/판결에 반응합니다. 생성 에셋을 이 프로젝트에 맞게 사용했습니다.

본문은 OFL 나눔명조의 필요한 글자를 추린 Court Myeongjo를 사용합니다. 수식은 TeX의 Times 계열 글리프를 벡터로 생성하고, 접근성용 MathML과 미등록 수식 대체 표시는 KaTeX로 제공합니다. 평가원 전용 글꼴을 복제한 것은 아닙니다. 그래프는 흑백 축·곡선·점선의 시험지 도식입니다. `MYEONGJO-OFL.txt`, `EXAM-MATH-NOTICE.txt`를 참고하세요.

수식을 수정하면 `node build-exam-math.mjs`로 벡터 캐시를 갱신하고 `npm run check`를 실행하세요. 게시 시 브라우저 캐시를 위해 app.js 및 연관 import 버전도 갱신합니다.
